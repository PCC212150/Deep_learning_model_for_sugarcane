# 按检查范围裁剪图片（框外涂黑）

用模型识别出的**检查范围（check_background）**裁剪图片：框内保留原样，框外全部涂黑。

**输出尺寸与输入完全一致**，框内像素停在原位 —— 坐标不变，所以 RSML 标注、掩码、
统计结果都还能直接对上，可以直接替换原图喂给训练/推理，**不需要重新映射标注**。
（要「只留框内那一块」的紧凑裁剪本工具不做；那种切法坐标会偏移。）

## 为什么用模型而不是标注

本工具走的是和 [inference.py](../../inference.py) / [test.py](../../test/test.py) **完全同一条
流水线**（[common/predict.py](../../common/predict.py) 的 `_fit_rect`），所以裁出来的框
**就是 overlay 图里那个绿框**，不会出现「工具裁的框 ≠ 推理时用的框」这种口径分裂。

代价是框有误差（实测与人工标注框的平均 IoU 0.98，最大偏差约 10px 量级），
换来的是**没有标注的图也能裁**（比如那批 96 张 CK 图）。

## 用法

必须在项目根目录下运行（脚本按项目结构找 `common/` 与 `config.py`）。

```
python tool\cut_pictures\cut_pictures.py --dir "D:\待裁剪图片"
python tool\cut_pictures\cut_pictures.py --dir "D:\待裁剪图片" --model model_202609151347
python tool\cut_pictures\cut_pictures.py --dir "D:\待裁剪图片" --out "D:\裁剪结果"
python tool\cut_pictures\cut_pictures.py --dir "D:\待裁剪图片" --dry-run
```

| 参数 | 说明 |
| --- | --- |
| `--dir` | 待裁剪的图片文件夹（**必填**；只处理这一层，不递归） |
| `--model` | 模型文件夹名（可省 `model_` 前缀）；省略 = 取 `model/` 下最新的 |
| `--out` | 输出文件夹。默认 `result/{源文件夹名}_cut/` |
| `--size` | 模型输入长边；默认用**模型训练时的设置**（从权重里读） |
| `--dry-run` | 只识别框并打印，不写任何文件 |
| `--cpu` | 强制用 CPU |

`--model` 也支持逗号分隔的**多模型集成**（见主 readme）。

## 输出

默认写到 `result/{源文件夹名}_cut/`（重名追加 `-1`、`-2` …，项目规范）：

- **裁剪后的图片** —— 文件名与扩展名都不变
- `cut_report.txt` —— 逐张记录「原图 → 框坐标 → 框尺寸 → 占图面比例 → 状态」

```
plant_ S062-1_20251116ST.png	框=(497,642)-(5317,3271)	4820x2629	占图面 63.5%	已裁剪
root_C001-1_20241229CK.jpg	框=(780,658)-(5306,3282)	4526x2624	占图面 59.5%	已裁剪
```

## 两个要注意的地方

**1. 检查范围识别失败的图不会被裁，也不会被跳过 —— 原图原样复制过去。**

占图面 <5% 或 >99.9% 时判定识别失败（同 [config.py](../../config.py) 的
`CHECK_MIN_RATIO` / `CHECK_MAX_RATIO`）。这时**原图复制**而不是涂成全黑或丢掉：
宁可交一张没裁的图，也不要交一张全黑的废图。这类图会在运行末尾单独列出来，
`cut_report.txt` 里状态是「检查范围未识别，原图复制」。

> 拿到这类图先用 [inference.py](../../inference.py) 看看 overlay，确认是模型的检查范围
> 通道不行、还是这批图本身特殊。**换模型比调阈值管用。**

**2. 输出沿用原扩展名，所以 jpg 源图会再被压缩一次。**

实测：png 源图裁出来**框内逐位相同、框外纯黑**；jpg 源图因为重新编码，框内会有
有损差异（目视无差别）。在意无损就把源图转成 png，或者裁完统一存 png。

## 性能

约 1.4~2.5 s/张（RTX 5060 Laptop，5472×3648，含读图 + 推理 + 写图）。
96 张大概 3~4 分钟。GPU 显存占用与 [inference.py](../../inference.py) 相同
（走同一条 `predict` 流水线）。
