# 裁掉 C/P 无法成对的图片（为实现对照）

C（`root_C###-#_<日期>CK.jpg`）与 P（`root_P###-#_<日期>PEG.jpg`）是两个处理。
做对照实验，要求**同一个「编号-重复-日期」两边各有一张**。实际数据里有两类坑：

| 情况 | 例子 | 处理 |
| --- | --- | --- |
| **异常命名** | `root_P137-1 (2)_20250108PEG.jpg`（带 `(N)` 标记） | 剔除 |
| **单边缺某天** | C 缺 `20250106`、P 缺 `20250110` | **两边都剔除** |

规则**纯按文件名**，不改名、不按图像内容猜归属：

```
异常命名的        -> 剔除
两边都有的日期     -> 保留
只有一边有的日期   -> 两边都剔除（保证严格一一对应）
```

## 用法

```
python tool\pair_cp\pair_cp.py --dir "E:\baiduwangpan\DownLoad" --dry-run   # 先预览
python tool\pair_cp\pair_cp.py --dir "E:\baiduwangpan\DownLoad"             # 正式执行
python tool\pair_cp\pair_cp.py --dir "..." --quarantine "D:\回收"           # 指定隔离目录
```

| 参数 | 说明 |
| --- | --- |
| `--dir` | 含 `C` 与 `P` 两个子文件夹的父目录（**必填**） |
| `--sides` | 两侧文件夹名，逗号分隔（默认 `C,P`） |
| `--quarantine` | 剔除文件的去处，默认 `<dir>\_剔除_CP对照\` |
| `--dry-run` | 只报告要剔除哪些，不动文件、不写日志 |

## 剔除的文件是「移走」不是「删除」

移到 `<dir>\_剔除_CP对照\<C|P>\` 里**原样未改**，配合日志可以随时搬回来。
确认无误后自行删掉隔离目录即可。

执行后在 `--dir` 下生成 `CP对照_剔除日志.csv`（UTF-8 BOM，Excel 直接打开），
逐条记录「侧 / 文件名 / 编号-重复 / 日期 / 剔除原因 / 隔离位置」，表头前有 5 行
`#` 注释写清本次的规则、保留数、剔除数与隔离目录。

## 实测（2026-09-17，`E:\baiduwangpan\DownLoad`）

```
C: 标准命名 6485 / 异常 0
P: 标准命名 6484 / 异常 4
两边都有（可对照）: 6473     C 独有: 12     P 独有: 11
剔除 27 个 -> C 剩 6473 / P 剩 6473   差集 0 / 0  严格一一对应
```

剔除的 27 个分三类：

- **异常命名 4 个**：`root_P137-1 (2)/(4)/(6)/(8)_20250108PEG.jpg`；
- **C 独有 12 个**：137-1/2/3/4 的 `20250108`、148-1..4 与 192-1..4 的 `20250110`；
- **P 独有 11 个**：013、091、179 的 `20250106`。

> **一处值得知道**：`C137-1@20250108` 本身完全正常，剔除它是因为 P 侧那一天的唯一
> 文件是异常命名的 `(8)`（P 的 4 个重复在 20250108 的照片被导出成了同一个名字，
> 加了 `(2)(4)(6)(8)` 标记）。按「异常命名先剔除、再保留两边都有的日期」的规则，
> 这对自然就配不上了。若要恢复这一天，得先把 `(8)` 归位成 `root_P137-1_20250108PEG.jpg`
> 再把它搬回来（图像比对结论：`(8)`→137-1、`(6)`→137-2、`(4)`→137-3、`(2)`→137-4）。
