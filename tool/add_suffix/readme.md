# 批量添加文件后缀工具

目的：给一个文件夹里的文件批量加后缀，**后缀插在扩展名之前**，文件名本身（含空格、中文）原样保留。

```
plant_ S062-1.png  ->  plant_ S062-1_20251116ST.png
a.rsml             ->  a_20251116ST.rsml
```

典型场景：把 `20251116ST` 这一批数据从 RootTracer 导出后，给文件夹里所有图片和 RSML 标注统一打上日期批次后缀，避免不同批次混在一起时重名。

## 运行环境

只用 Python 标准库（`argparse` / `pathlib`），**不需要任何第三方依赖**，任意 Python 3 均可直接运行；
在本项目里用 Anaconda 环境 `pcc` 即可（`conda activate pcc`）。

## 使用方法

1）**先预览**（推荐先跑一次，确认待改名的列表没问题）：

```
cd tool\add_suffix
python add_suffix.py --dir "C:\Users\21215\Desktop\20251126ST" --add "_20251116ST" --dry-run
```

2）**确认后正式执行**（去掉 `--dry-run`）：

```
python add_suffix.py --dir "C:\Users\21215\Desktop\20251126ST" --add "_20251116ST"
```

也可以不切目录，在项目根目录下运行：

```
python tool\add_suffix\add_suffix.py --dir "C:\Users\21215\Desktop\20251126ST" --add "_20251116ST"
```

## 参数

| 参数 | 必填 | 说明 |
| --- | --- | --- |
| `--dir` | 是 | 目标文件夹路径。路径含空格时必须用引号包住，如 `"C:\Users\21215\Desktop\雨寒\大创的数据集"` |
| `--add` | 是 | 要添加的后缀内容，如 `_20251116ST`（建议带上 `_` 或 `-` 分隔，可读性更好） |
| `--exts` | 否 | 逗号分隔的扩展名，默认 `.png,.jpg,.jpeg,.rsml,.txt`。只处理列表内的扩展名，其他文件不动 |
| `-r` / `--recursive` | 否 | 递归处理子文件夹（默认只处理 `--dir` 这一层） |
| `--dry-run` | 否 | 只打印将要改名的文件，**不实际改名** |
| `--force` | 否 | 文件名已含该后缀时也再加一次（默认会跳过，见下） |

命令行里加 `-h` 可查看帮助：`python add_suffix.py -h`。

## 行为说明

- **后缀插在扩展名之前**：`plant_ S062-1.png` + `_20251116ST` → `plant_ S062-1_20251116ST.png`，
  而不是 `plant_ S062-1.png_20251116ST`。
- **重复执行安全**：文件名（不含扩展名）已经以该后缀结尾时自动跳过。
  所以同一批数据跑两遍，不会变成 `xxx_20251116ST_20251116ST`。
- **不覆盖文件**：如果改名后的目标文件已存在，该文件跳过并提示，不会覆盖已有文件。
- **只动指定扩展名**：默认只处理 png / jpg / jpeg / rsml / txt，其他文件（如 `.me`、`.csv`）不碰。
- **大小写不敏感**：`.PNG`、`.JPG` 也会被处理。
- **改名不可逆**：脚本没有"撤销"功能，正式执行前建议先 `--dry-run` 过一遍。

## 输出示例

```
文件夹：C:\Users\21215\Desktop\20251126ST
后缀：_20251116ST    扩展名：.jpeg,.jpg,.png,.rsml,.txt    仅当前层    共 4 个文件
[改名] a.rsml  ->  a_20251116ST.rsml
[改名] b.txt  ->  b_20251116ST.txt
[改名] plant_ S062-1.png  ->  plant_ S062-1_20251116ST.png
[跳过] 已改名_20251116ST.png  （文件名已含该后缀）

完成：改名 3 个，跳过 1 个（已含后缀 1，目标重名 0）
```

- `[改名]` —— 已成功改名
- `[跳过] （文件名已含该后缀）` —— 之前已经加过，未重复添加
- `[跳过] （目标已存在：xxx）` —— 改名后会撞上同名文件，未改动。
  出现这种情况说明文件夹里混有已改过名的文件，请先核对再处理。

## 常见问题

- **`[错误] 文件夹不存在`**：`--dir` 路径写错或该路径不是文件夹。路径里有空格/中文时记得加引号。
- **提示后缀不能为空**：`--add` 后面没写内容，或写成了 `--add ""`。
- **只想处理部分扩展名**：用 `--exts` 覆盖默认值，例如 `--exts png,rsml`。
- **想改回来**：目前需要手动批处理，或另写脚本把后缀去掉（注意别把本来就带该后缀的原始文件误改）。
